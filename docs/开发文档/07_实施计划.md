# token-route 实施计划（P1 编码路线）

> 对齐 procurement 22 号先例：每步 ≤1000 行，流程 = 读相关章节 → 写测试 → 写业务 → 测试 → 修复 → 优化（P0~P2，≤4 轮或无 P0~P2 收步）；每步结束更新本仓 `CODING-PROGRESS.md`（续作锚点）。
> 触发条件：token-gateway M2.5 任务面启动（第二消费方确认，01 §10）。
> **V2.0**：随核心流程重定义重组——config 种子加载与脚本引擎提前（S1），管理面 CRUD 删除，新增容量记账（S3）。
> **V2.1 评审收口**：确定性 entry_id 工具类前置 S2；report 三态全记账 + 10700 只补发 rejected；**channel-legacy 预设移出 V1**（P2）；**S2 影子比对件删除**（08 #3 随 LLM 面不迁而取消）。

## 1. 技术栈与工程坐标

| 项 | 值 |
|---|---|
| 工程 | 独立仓 `funcommons/token-route`，groupId `fun.commons`，artifactId `token-route`，包名 `fun.commons.tokenroute`（前缀 `Tr`：TrCode / TrProperties / TrResolveService…） |
| 栈 | Java 17 + Spring Boot 3.5（对齐 token-gateway）+ fwk4j v1.5.1（web / accesstoken / redis，本地 m2）+ Redisson（fwk4j-redis 传递）+ **Groovy（脚本引擎，显式依赖，05 号）** |
| 存储 | Redis only，无 PG 无 Flyway |
| 测试 | JUnit5 + AssertJ + Testcontainers **1.21.4**（Redis 容器；1.20.6 与 Docker Desktop 29 不兼容，thmp 教训） |
| 脚本 | Groovy + SecureASTCustomizer（借 MMagiX groovy-engine 先例，05 号） |
| 端口 | 9302 |

## 2. 分期步骤

## 3. 测试与安全向量（贯穿各步）

| # | 向量 | 落点 |
|---|---|---|
| 1 | 鉴权模式矩阵（none 直过 / apikey 错 key 401 / jwt 过期·篡改 10200；contract 与 ops 面互不可越） | S0/S5 |
| 2 | 调用方归因（X-Caller-Id 缺省/携带均不拦截，仅落 `[TR-RESOLVE] caller=`） | S2 |
| 3 | 脚本沙箱逃逸全套（05 §7）+ 超时中断 + fail-fast | S1 |
| 4 | 容量记账边界（并发满载过滤 / 桶窗口滚动 / rate_units 三口径 / 租约超时回收序列 / 回收×report 竞态） | S2/S3 |
| 5 | 状态机边界（default 单预设：min-calls 9/10、ratio 0.49/0.50、退避序列、FEED 显式 ACTIVE 解冻；channel-legacy 预设 P2 不在 V1） | S3/S4（Clock 注入，禁 Thread.sleep） |
| 6 | 竞态三件（同 session 并发绑定单 NEW + 败者采用 / 评估器多实例锁 / FEED 拉取单飞不叠拉） | S2/S4 |
| 7 | Redis 故障语义（resolve EMPTY 不 5xx / report 10700 / 表壳内存不受影响 / 恢复回源自愈） | S7（容器 pause/恢复注入） |

## 4. 质量门槛（mc-test）

- 覆盖率：服务线行 ≥80% / 分支 ≥70%（JaCoCo 0.8.13，对齐 thmp 现状口径）；`TrCode` / 脚本引擎 / 退避与租约计算 Util 线 ≥90%。
- IT 需 Docker（Testcontainers）；CI 无 Docker 环境跑单测切片 + `tr.scheduler.enabled=false`。
- 每步收步标准：新增用例全绿 + 无 P0~P2 优化残留 + CODING-PROGRESS.md 更新。

## 6. 依赖与顺序约束

- S1（脚本引擎）为 S2 选择器/过滤的前置；S2 依赖 S0 种子加载（表存在才可 resolve）；S3 依赖 S2 预占（lease 语义成对）；S4 依赖 S3 的窗/连败键；
- S6 可与 S4/S5 并行（SDK 以 02 契约为准，服务端未完成前用 MockWebServer 开发）；
- token-gateway M2.5 消费方接入在 S6 出口后启动（任务面 resolve + report 全链冒烟 = 01 §10 P1 总出口）。
