# 上线检查单（token-route 生产部署）

> 逐项勾选后再放量。配置细节见 `配置手册.md`，告警阈值见 `SLI告警建议.md`，
> 双实��互斥的实测手段见 `scripts/verify-ha.sh`（约 4 分钟）。

## 1. 安全（放行前必查，全部默认值都是开发值）

- [ ] `JWT_SECRET` 已轮换（默认 `tr-dev-secret-key-please-rotate-32ch`，≥32 字符随机）
- [ ] `JWT_SALT` 已轮换（默认 `tr-salt`）
- [ ] `TR_API_KEY` 已轮换（默认 `dev-api-key`；apikey 模式时即消费方密钥）
- [ ] `tr.auth.contract-mode` 已按选型设置（内网 none / 跨边界 apikey / jwt；生产**不建议** none 跨信任边界）
- [ ] ops 面 `tr.auth.ops-mode=jwt` 保持默认（policy `tr-admin`）
- [ ] `/actuator/**` 暴露面收敛：网络隔离，或设独立 `management.server.port` 只绑内网（见配置手册 §7）
- [ ] FEED 上游 `refresh_url` 可达性仅限服务网段（FEED 是唯一条目写入口，防伪造回源）

## 2. 数据与依赖

- [ ] Redis 开启 AOF（compose 默认 `--appendonly yes --appendfsync everysec`）；确认生产实例同策略
- [ ] Redis 未使用 Cluster（声明不支持，01 §设计方案 V2.1）
- [ ] `tr.key-prefix` 与多套环境共存的规划一致（默认 `tr`）
- [ ] 内存预估：10 表 × 200 条目 ≈ 条目 JSON + 计账键，数百 MB 内；已设 maxmemory 策略
- [ ] FEED 上游 SLA 已知：token-route 失败保旧值（≥3 次连续失败告警），上游故障不丢条目只停更新

## 3. 部署（双实例水平扩展）

- [ ] 双实例部署，环境变量 `TR_REDISSON_ENABLED=true`（评估器 Redisson tryLock(0) 多实例互斥；
      单实例可省——退化本地锁语义）
- [ ] **互斥实测**：`bash scripts/verify-ha.sh` → `HA PASS`（观察窗内两实例 `tr_evaluator_run_total`
      增量之和 ≈ 评估轮数；若 ≈ 2×轮数即互斥失效，禁止放量）
- [ ] 实例无状态确认：不落盘、会话态全在 Redis；LB 轮询任意实例等价
- [ ] 健康检查接 LB：`GET /v1/ping`（或 `/actuator/health`，含 `tokenRouteRedis` 组件）
- [ ] 优雅停机生效：SIGTERM 后在途请求处理完再退（`server.shutdown: graceful`，30s 预算）

## 4. 可观测接入

- [ ] Prometheus 抓取 `GET /actuator/prometheus`；SLI 指标对照见 `SLI告警建议.md` §指标对照
- [ ] 告警规则按 `SLI告警建议.md` 阈值表落库（P0：EMPTY 率 / Redis 连通；P1：FEED 失败 / script 降级 / 状态迁移突增）
- [ ] 结构化日志（`[TR-RESOLVE]`/`[TR-STATE]`/`[TR-FEED]`）落文件并接日志管道（Loki 为 M4 项，过渡期文件 + 轮转）
- [ ] 表种子（`tr.tables`）与 FEED 上游清单评审过：strategy / capacity / refresh_interval 逐表确认

## 5. 上线后验证（放量前最后一轮）

- [ ] `bash scripts/smoke-s0.sh` 三项契约冒烟全绿
- [ ] 消费方按 `token-gateway接入指引.md` 走通一次闭环（resolve → 真实调用 → report → 亲和 HIT）
- [ ] 人为 `kill` 一实例：LB 摘除、另一实例继续服务；重启后 FEED/评估自动恢复（无状态验证）
- [ ] 观察首个 30 分钟：`tr_resolve_total` EMPTY 率、`tr_feed_pull_total` 失败率、`tokenRouteRedis` 健康

## 6. 回滚

- [ ] 镜像回退即回滚（无 schema、无数据迁移；条目数据真源在上游 FEED，回滚后 refresh ping 自愈）
- [ ] 配置回滚 = 改环境变量滚动重启（表壳/鉴权/锁开关全部 env 化）
- [ ] Redis 数据不需要清理：key 带 `tr:` 前缀，条目键 TTL 自愈；紧急时 FLUSHDB 后依赖 FEED 回源
