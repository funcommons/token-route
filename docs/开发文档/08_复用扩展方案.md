## 2. 「场景覆盖」的定义（V2.0 修订，防目标漂移）

**成立**：MMagiX/TokenGo 的**中低 QPS 调度/任务类路由场景** → token-route 内核直接覆盖，或脚本/预设覆盖，或族内组合件覆盖（转发 = gateway4j/onetoken4j，审计 = Loki）。

**不适配（明确排除，非缺口）**：高 QPS 低延迟热路径（每次调用直连 +1 跳、无 SDK 本地缓存兜底，01 §11#2）——MMagiX LLM 同步面即此类，**确定不迁**。

组合公式（V2.0）：

```text
决议 + 并发预占（token-route）+ 转发（gateway4j/onetoken4j）+ 接入件（token-route-sdk 薄件）+ 审计（Loki）
= 完整调度/中转能力，全部复用族内件，零自建路由
```

## 4. 平台适配映射（V2.0 重写）

### MMagiX

| # | 场景 | 判定 | 说明 |
|---|---|---|---|
| 1 | LLM 同步面候选解析 | ❌ **确定不迁**（原 #1~#4/#6 合并判定） | 热路径每次直连 +1 跳且无 SWR 兜底；供给语义（逐租户 key 密文/成本缺失）装不进不透明条目；THMP 契约冻结（18 号 §3.1，CCB 防线）；W3 切流在即（组织纪律） |
| 2 | 健康状态机同构语义（连 3 ×0.5 / 连 5 禁用） | ⚠️ P2（channel-legacy 预设） | LLM 面不迁后无 V1 消费方——预设随 P2（THMP S3 远期收敛同批）交付；解冻语义 = FEED 显式 ACTIVE（01 §4.2） |
| 3 | 信号源差异（feedHealth/call_log → report 三态） | ❌ **随 #1 取消**（V2.1） | LLM 面不迁则 THMP 事件无 report 落点；仅当未来任务域需要 THMP 健康信号时重启评估（消费方侧桥接件 ~200 行） |
| 4 | 渠道运营 UI | ⚠️ 降级为只读展示 | 零管理写面：MMagiX 管理台可挂 ops 面（TR-OPS-001~004）做状态/日志展示 + refresh ping；**调权重/上下线走上游 FEED 数据** |
| 5 | 未来非 LLM 任务域路由 | ✅ 首选落点 | 触发 P1 立项（01 §10） |

### TokenGo

| # | 场景 | 判定 | 说明 |
|---|---|---|---|
| 1 | 渠道调度接入（任务/供给选择） | ✅ 首要扩展消费方 | T1：SDK/HTTP 直连 resolve/report + gateway4j 转发 + Loki；备份 = 部署制品 + 上游真源（见 #5） |
| 2 | 计费强耦合路由 | ✅ 模式约定 | 调用方 resolve 前查余额拼 `biz_params`，filter 脚本 `num(params.balance) >= num(entry.data_json.min_balance)` 过滤——决议保持无状态，不做服务端账户联动 |
| 3 | 流量代理 | ✅ 组合 | gateway4j/onetoken4j 转发（族内既有件） |
| 4 | 非 JVM 消费端 | ✅ OpenAPI 导出件 | 各语言薄客户端按需自实现 |
| 5 | 配置进 DB 备份体系 | ✅ 模式变更（V2.0） | 表壳 = config 文件（随部署版本化）、条目 = 上游真源回源自愈——**无快照对象，备份 = 部署制品 + 上游**，比快照导出更简 |
| 6 | 管理台 | ⚠️ 同 MMagiX #4 | ops 只读展示 + refresh ping |
| 7 | 限流/熔断 | ✅ 各自持有 | 调用方/用户·key 限流不在 token-route 范围（01 §3 非目标）——TokenGo 网关侧挂 mc-cache RRateLimiter；token-route 只做条目容量治理（上游限速/限并发） |
| 8 | LLM 供给段（若做 LLM 中转） | ⚠️ 调度段可、热路径不可 | 同 MMagiX #1 判定：非热路径的供给调度可用；同步推理面不适配 |

### 通用边界

| # | 边界 | 闭环 |
|---|---|---|
| 1 | 亲和单绑（无多播/主备组） | 多播 = 调用方并发多 resolve；主备 = 消费方 failover 重新 resolve（fallbacks 已删） |
| 2 | 日志热窗 7d | Loki 全量（族内标准） |
| 3 | Redis 可用性 | 表壳内存不受影响 + FEED 回源自愈（01 §9）；消费方自备降级预案 |

| 平台 | 阶段 | 内容 |
|---|---|---|
| MMagiX | R1（现在起） | 新非 LLM 任务域路由直接落 token-route（第二消费方 → 触发 P1 立项）；状态机预设/OpenAPI 随 P1 交付 |

## 6. 明确不做（V2.0 内核边界）

- ❌ 流量代理 / 重试代理（决议与转发分层）
- ❌ **调用方/用户·key 限流**（网关/业务侧职责；token-route 只做条目容量治理）
- ❌ 服务端实时账户联动（决议无状态；调用方拼 biz_params + filter 脚本）
- ❌ 多播/主备组亲和（扇出由调用方并发实现）
- ❌ 内核 LLM 语义（供给语义走 profile + 脚本，内核保持条目不透明）
- ❌ 管理写面（表壳 config 种子化；变更 = 滚动重启）
- ❌ SDK 本地缓存/SWR/ver（预占直连模式冗余）
