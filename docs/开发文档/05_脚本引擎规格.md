# token-route 脚本引擎规格（Groovy 沙箱 · V2）

> 01 §5.4 定稿「Groovy 沙箱统一引擎」的落地规格：选型 ADR、沙箱三件套、上下文、两用途语义、故障降级、示例与测试向量。
> 两个用途：① 表级 `filter_script`（条目过滤谓词）② `selector_script`（集合级选择器，返回条目 ID）。

## 1. 引擎选型（ADR）

| 项 | 决策 |
|---|---|
| 决策 | **Groovy**（编译至字节码 + `SecureASTCustomizer` 编译期白名单 + 执行期超时中断），借 **MMagiX groovy-engine 沙箱先例**（三件套现成件） |
| 备选 A | SpEL 表达式（V1.0~V1.5 方案）——仅支持「每候选独立求值」的排序键/谓词语义，**装不下集合级选择器**（脚本需遍历条目集并返回条目 ID），V2.0 弃 |
| 备选 B | Aviator——LGPL 许可违反 SDK 白名单红线，不引 |
| 备选 C | 自写解释器——维护面最大，弃 |
| 决策依据 | 集合级选择器是拍板需求（V2.0 边界修正②）；groovy-engine 先例使沙箱风险可控；脚本以**文件形态**随部署制品走评审/版本化（config 种子化，无 API 写面 → 无注入入口） |
| 依赖 | groovy（SDK 白名单内，Apache-2.0）；fwk4j/Boot 传递面之外新增一个显式依赖 |

## 2. 沙箱三件套

| # | 机制 | 内容 |
|---|---|---|
| 1 | **编译期白名单**（`SecureASTCustomizer`） | 禁 import；语句类型白名单（表达式/return/def 声明）；表达式白名单（二元/三元/方法调用/属性访问/闭包）；**禁 while/for 语句**（集合遍历只走白名单闭包方法）；接收者类型白名单（§4 上下文对象 + Java 集合/数值/字符串）；禁 `System`/`Runtime`/`Thread`/反射/IO/`new` 任意类（仅白名单构造） |
| 2 | **执行期防护** | 脚本在独立执行上下文运行 + **超时中断**（`tr.engine.script-timeout-ms`，默认 100ms，超时抛 `ScriptTimeoutException`）；递归深度受限（白名单禁自调用定义面） |
| 3 | **编译 fail-fast** | config 启动加载即编译全部脚本，失败 → 10630 + 指名表/脚本 **拒绝启动**（坏脚本进不了线上；无热更、无 API 写面，变更 = 换文件 + 滚动重启） |

> 攻击面论证：脚本来源仅部署制品（评审/版本化），无运行时上传通道；沙箱为纵深防御而非唯一边界。

## 3. 上下文绑定（脚本可见变量，封闭集）

| 绑定 | 类型 | 说明 |
|---|---|---|
| `params` | Map | resolve 请求 `biz_params` 原样（值 string/number） |
| `entry` | Map | 单条目视图：`{entry_id, name, weight, order_no, data_json…}`（filter 用） |
| `entries` | List<Map> | 过滤后候选条目集（selector 用） |
| `now` | long | epoch 毫秒（求值时刻） |
| helper | 函数 | `num(v)`（string→number 安全转换，null/非法→**0**——⚠️ 用于 min/max 选择器时缺值条目会以 0 参与比较，见 §6 警示）/ `str(v)` / `len(v)`（string 长度或集合大小）/ `in(v, coll)` / `min(coll)` / `max(coll)` |

## 4. 两用途语义

| 用途 | 签名 | 求值结果语义 |
|---|---|---|
| 表 `filter_script` | `(params, entry) → boolean` | `true` 留 / `false` 出局；**正常求值但非 Boolean → 该条目出局**（fail-closed） |
| 策略 `selector_script` | `(params, entries) → entry_id(string)` | 返回候选集内存在的 `entry_id`；返回 null/不存在/非 string → **回退表默认策略**（加权随机）；`strategy_type=SCRIPT` 且无默认可退 → EMPTY + `SCRIPT_DEGRADED` |

## 5. 故障降级（脚本故障不放大为路由不可用）

| 阶段 | 故障 | 语义 |
|---|---|---|
| 启动（config 加载） | 编译失败 / 超长 / 白名单命中 | 10630 **拒绝启动**（fail-fast），日志指名表/脚本与错误位置 |
| 运行（resolve 内） | filter 单条目求值异常/超时 | 该条目出局（等价 false）+ `[TR-SCRIPT]` warn（每次 resolve 至多告警一次）+ 计数器 |
| 运行（resolve 内） | selector 异常/超时/返回非法 | 回退表默认策略；SCRIPT 唯一策略 → EMPTY + reasons 追加 `SCRIPT_DEGRADED` + 计数器（SLI：script_degraded_total） |

## 6. 示例集

```groovy
// filter 1. 价格上限 + 模型支持
num(params.price) <= num(entry.data_json.max_price) && in(params.model, entry.data_json.models)

// filter 2. 租户白名单（data_json.tenants 缺省 = 公共）
len(entry.data_json.tenants) == 0 || in(params.tenant, entry.data_json.tenants)

// filter 3. 地区白名单
len(entry.data_json.regions) == 0 || in(params.region, entry.data_json.regions)

// selector 1. 价格优先（成本最低者胜出·先剔除缺价条目，防 num() 零值陷阱）
def priced = entries.findAll { it.data_json.unit_price != null }
priced.isEmpty() ? null : priced.min { num(it.data_json.unit_price) }.entry_id

// selector 2. 加权优先（有效权重 = weight × 健康系数，含降级）
def best = entries.max { num(it.weight) * (it.status == 'ACTIVE' ? 1.0 : 0.5) }
best.entry_id

// selector 3. 租户过滤 + 成本优先组合（同样剔除缺价条目）
def ok = entries.findAll { (len(it.data_json.tenants) == 0 || in(params.tenant, it.data_json.tenants)) && it.data_json.unit_price != null }
ok.isEmpty() ? null : ok.min { num(it.data_json.unit_price) }.entry_id
```

> ⚠️ **num() 零值陷阱（V2.1）**：`num()` 对缺值/非法返回 0——选择器直接 `min { num(it.data_json.unit_price) }` 会让**未配价条目以 0「胜出」**。选择器场景必须先 `findAll { it.data_json.unit_price != null }` 剔除（上方示例已按此写法）；filter 场景 0 缺省通常安全（无价 = 不可比 = 拒绝）。

## 7. 测试向量挂钩（实施计划 S1 出口）

| 向量 | 断言 |
|---|---|
| 沙箱逃逸 | `System.exit(1)`、`Runtime.getRuntime()`、`Thread.sleep`、`File`/IO 构造、`evaluate`/反射、`while(true)` 全部**编译期拒绝**（启动失败 10630） |
| 超时中断 | 白名单闭包构造深嵌套 `collect` 大集 → 执行超时抛 `ScriptTimeoutException` → 按 §5 降级 |
| 类型边界 | filter 返回 number/string → 条目出局；selector 返回不存在 entry_id / null → 回退默认策略 |
| 编译 fail-fast | config 挂载坏脚本 → 启动失败且日志指名表/脚本 |
| 降级计数 | selector 异常 → 回退生效 + `[TR-SCRIPT]` + script_degraded_total +1；每次 resolve 至多一条告警 |
