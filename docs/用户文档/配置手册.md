# token-route 配置文档

> 全量配置项参考（`tr.*` 前缀，对齐 thmp-app `thmp.*` 惯例）。敏感项一律环境变量注入，禁入仓（mc-java-spec）。
> 读者：**部署/管理方**（建表、调参、鉴权、FEED 接入）；消费方通常只需 table_id 与参数口径，无需读本册。建表/运维操作走查见 [02_管理与运维手册.md](./02_管理与运维手册.md)。
> **V2.0**：`tr.tables` 表定义种子为本仓核心配置——表壳 + 脚本文件挂载，启动加载、编译 fail-fast，变更 = 滚动重启（零管理写面，01 §5.6）。
> **V2.1**：§3 字段表与 yaml 样例统一为 nested 结构（`affinity.*` / `feed.*`）；`state-policy` V1 仅 `default` 预设；补脚本表规模指引。

## 1. 基础与依赖

| 配置 | 默认 | 说明 |
|---|---|---|
| `spring.application.name` | `token-route` | — |
| `server.port` | `9302` | 中台族端口：thmp-app 9300 / compose 公网组 9301 / **token-route 9302** |
| `spring.data.redis.*` / fwk4j MultiRedis `redis.datasources.main.*` | localhost:6379 | 唯一存储；生产独立实例 |
| `spring.flyway.*` | — | **无**（无实体表，无 PG 依赖） |

## 2. 鉴权（三模式：none / apikey / jwt，无凭证签发/轮换）

| 配置 | 默认 | 说明 |
|---|---|---|
| `tr.auth.contract-mode` | `none` | 契约面鉴权：`none`（内网信任）/ `apikey`（`X-Api-Key` 头比对）/ `jwt`（fwk4j-accesstoken，policy `tr-client`）；覆盖 `/v1/resolve|report|affinity|refresh/**` |
| `tr.auth.ops-mode` | `jwt` | 运维只读面 `/v1/ops/**`（同三值；jwt 模式 policy `tr-admin`）；生产建议保持 jwt |
| `tr.auth.api-key` | — | apikey 模式共享密钥（env `TR_API_KEY` 注入；单 key，轮换 = 双端改配置滚动重启） |
| fwk4j-accesstoken policies（`tr-admin` / `tr-client`）+ `hash-salt` | — | **仅 jwt 模式需要**；token 由平台统一认证签发，token-route 只验不签 |

## 3. 表定义种子 `tr.tables`（V2.0 核心）

启动加载 → 脚本编译 fail-fast（10630 拒绝启动）→ 表注册表进进程内存；**运行期无写接口**，变更 = 改配置 + 滚动重启。

| 字段 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| `name` | string | 是 | — | 即 `table_id`（消费方按 name 引用） |
| `tenant-id` | string | 否 | `0` | 归属租户（0=公共），管理域组织用 |
| `strategy-type` | enum | 是 | — | `WEIGHTED_RANDOM` / `ROUND_ROBIN` / `WEIGHT_FIRST` / `SCRIPT` |
| `selector-script` | string | SCRIPT 必填 | — | 选择器脚本文件路径（`file:/conf/tr-scripts/llm-selector.groovy`），05 号 |
| `filter-script` | string | 否 | — | 过滤谓词脚本文件路径（可省略 = 不过滤） |
| `affinity.enabled` | boolean | 是 | — | 亲和开关（与 yaml 样例 nested 结构一致） |
| `affinity.idle-timeout-seconds` | int | 否 | `28800` | 空闲脱离（8h） |
| `affinity.max-failures` | int | 否 | `5` | 绑定条目连败脱离阈值 |
| `lease-ttl-seconds` | int | 否 | `30` | 并发租约超时（超时惰性回收，01 §5.2） |
| `state-policy` | string | 否 | `default` | 状态机判定参数组；**V1 仅 `default`（窗口制）**——`channel-legacy` 预设 P2（01 §4.2） |
| `data-profile` | string | 否 | `generic` | 载荷标注：`generic` / `llm-supply` / `notify-channel`（不校验内容） |
| `feed.refresh-url` | string | 是 | — | FEED 拉取源（全 FEED 模式下每表必填） |
| `feed.interval-seconds` | int | 否 | `60` | 惰性刷新周期 |
| `status` | string | 否 | `ACTIVE` | 表开关（OFFLINE = 全表停用，resolve → EMPTY + `TABLE_OFFLINE`） |

```yaml
tr:
  tables:
    - name: llm-supply
      strategy-type: SCRIPT
      selector-script: file:/conf/tr-scripts/llm-selector.groovy
      filter-script: file:/conf/tr-scripts/tenant-cost-filter.groovy
      affinity:
        enabled: true
        idle-timeout-seconds: 1800
        max-failures: 5
      lease-ttl-seconds: 30
      state-policy: default             # V1 仅 default（channel-legacy 预设 P2）
      data-profile: llm-supply
      feed:
        refresh-url: http://supply-system:9100/v1/routes/llm-channels
        interval-seconds: 60
    - name: video-task-upstreams
      strategy-type: WEIGHTED_RANDOM
      affinity:
        enabled: true
      feed:
        refresh-url: http://task-infra:9200/v1/routes/video-upstreams
```

> 脚本文件随部署制品（挂载卷/镜像层）走评审与版本化；`file:` 相对路径以工作目录解析。**规模指引（V2.1）**：SCRIPT / filter_script 表建议条目 ≤ 数百——filter 逐条目求值、selector 集合级构建 Map 视图，每次 resolve 成本与条目数线性相关；`tr.feed.max-entries-per-table`（§6）为非脚本表硬顶。

## 4. 运行时参数（默认值 = 01 定稿值）

| 配置 | 默认 | 说明 |
|---|---|---|
| `tr.affinity.default-idle-timeout-seconds` | `28800` | 亲和空闲超时全局默认（表级可覆盖） |
| `tr.affinity.default-max-failures` | `5` | 连败脱离全局默认 |
| `tr.resolve.default-lease-ttl-seconds` | `30` | 并发租约全局默认（表级可覆盖） |
| `tr.state.window-ms` | `60000` | 滑动窗 1m |
| `tr.state.min-calls` | `10` | 窗内调用数评估门槛 |
| `tr.state.degrade-ratio` | `0.50` | 失败率降级线 |
| `tr.state.recover-ratio` | `0.10` | 恢复线（<10% 或无失败，一步恢复） |
| `tr.state.consecutive-failures-freeze` | `5` | 连败冻结阈值（即判即升） |
| `tr.state.freeze-base-seconds` | `300` | 冻结基数 5min |
| `tr.state.freeze-backoff-factor` | `4` | 指数退避因子（5m→20m→80m→320m→封顶） |
| `tr.state.freeze-max-seconds` | `7200` | 冻结封顶 2h |
| `tr.report.max-batch` | `100` | 单请求回填上限（越界 10100） |
| `tr.ring.max-len` | `1000` | LTRIM 上限 |
| `tr.ring.ttl-days` | `7` | ring 热窗 |

## 5. 脚本引擎（05 号）

| 配置 | 默认 | 说明 |
|---|---|---|
| `tr.engine.script-timeout-ms` | `100` | 单次脚本执行超时（超时按 05 §5 降级） |
| `tr.engine.script-max-length` | `4096` | 脚本文件字符上限（超长 10630 拒启） |

## 6. 调度与 FEED 拉取

| 配置 | 默认 | 说明 |
|---|---|---|
| `tr.scheduler.enabled` | `true` | 测试切片置 false 直调 Job（对齐 thmp `thmp.scheduler.enabled`） |
| `tr.scheduler.evaluate-fixed-delay-ms` | `60000` | 评估器节拍 |
| `tr.scheduler.lease-seconds` | `60` | Redisson 锁 lease（业务时间 < leaseTime） |
| `tr.feed.pull-timeout-ms` | `3000` | 惰性/立即/冷启动回源超时 |
| `tr.feed.failure-alert-threshold` | `3` | 连续失败告警阈值（保旧值） |
| `tr.feed.max-entries-per-table` | `10000` | 单表条目上限（防上游异常响应撑爆，越界 10633） |

> ~~`tr.snapshot.*`~~：V2.0 删除（表壳=config、条目=上游真源，无快照对象）。

## 7. 可观测

| 配置 | 默认 | 说明 |
|---|---|---|

## 8. 生产 application.yml 样例

```yaml
spring:
  application:
    name: token-route
server:
  port: 9302

redis:                      # fwk4j MultiRedis
  datasources:
    main:
      host: ${TR_REDIS_HOST}
      port: ${TR_REDIS_PORT:6379}
      password: ${TR_REDIS_PASSWORD}

tr:
  auth:
    contract-mode: ${TR_AUTH_MODE:none}   # none / apikey / jwt
    ops-mode: jwt
    api-key: ${TR_API_KEY:}               # 仅 apikey 模式
  engine:
    script-timeout-ms: 100
  feed:
    pull-timeout-ms: 3000
  tables:
    - name: llm-supply                    # 完整样例见 §3
      strategy-type: SCRIPT
      selector-script: file:/conf/tr-scripts/llm-selector.groovy
      affinity:
        enabled: true
      state-policy: default
      data-profile: llm-supply
      feed:
        refresh-url: http://supply-system:9100/v1/routes/llm-channels

# jwt 模式另需 fwk4j-accesstoken 配置（policies tr-admin/tr-client + hash-salt）同 thmp-app 形态
# 敏感项全部 ${ENV} 注入：TR_REDIS_PASSWORD / TR_API_KEY / JWT 密钥 / hash-salt
```

## 9. 环境变量清单（部署面）

| 变量 | 用途 | 必填 |
|---|---|---|
| `TR_REDIS_HOST` / `TR_REDIS_PORT` / `TR_REDIS_PASSWORD` | Redis 连接 | 是 |
| `TR_AUTH_MODE` | 契约面鉴权模式（none/apikey/jwt） | 否（默认 none） |
| `TR_API_KEY` | apikey 模式共享密钥 | apikey 模式必填 |
| `TR_JWT_SECRET`（随 fwk4j policy 配置） | jwt 模式验签密钥（两面） | jwt 模式必填 |
| `TR_HASH_SALT` | fwk4j accesstoken hash-salt | jwt 模式必填 |
